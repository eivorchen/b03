### 自动化验证范围

Node 测试共 32 项：18 项引擎、13 项状态机、1 项静态资源引用图验证。引擎包含两关 × 三/四/五次 × 500 局的 3,000 局随机真源一致性检查，以及 1,000 局紧密共线数值回归；这些是程序用例，不是玩家试玩。

浏览器回归共 20 项，通过公开界面与 DOM 操作。预期源在 Node 端按开发种子独立生成，不读取或修改浏览器隐藏游戏状态。包括：

- 两关各自三、四、五次测量的完整流程；选点不扣次数、取消、连点防重、测量中锁定、最终确认才揭晓。
- 测量中重玩、切关、返回首页，旧测量不污染新局；两页面状态独立。
- 历史记录仅强调测点；共线镜像解被认可，提交前无候选提示。
- 两关演示完整结束、重看、跳过；结果页演示返回原结果；后续测量仍能完成。
- Chrome 触控模拟的多指、原生滚动和取消手势不扣次数，取消后可再次正常选点。
- 横竖尺寸变化后测点、读数、待测点和源保持一致，地图比例为 1.6，最终触点定位仍正确。
- 资源全部加载后将浏览器上下文置为离线，完成两关、演示、切关及重玩。
- 模块失败、CSS 失败和模块请求一直挂起时显示失败重试；恢复后重新进入游戏。
- `/b03/` 子路径下资源加载成功，刷新返回可用开始页。

自动化等待使用 Playwright 时钟推进，不代替真实等待体验评估。另在可见 Chrome 页面手动打开游戏、演示、选点、确认测量，并检查手机尺寸与第二关布局。

### 历史修复记录与限制

浏览器检查中修复了演示结束移除计时节点、结果页重看演示访问旧 DOM、CSS 失败事件早于模块监听、取消触摸影响下一次点按、导航保留旧滚动位置以及请求挂起没有总超时等问题。最初测试脚本的时钟暂停竞态和文本换行断言也已修正；最终结果以原始日志为准。

未推送远程、未发布 Pages、未改安全设置。首次网络安装和本机服务曾因旧的只读任务范围被自动审批拒绝；确认未执行后，收到新的开发授权证据并按原操作重试成功，当前无此阻塞。

首版仍需真实设备与现场网络验收，以及 10—15 名非专业参与者试玩。本文不宣称已达到扫码成功率、平均用时、玩家成功率或全浏览器兼容性。0.1.0 使用三次测量、三秒等待；0.2.0 已将本轮默认改为四次、一秒。屏障布局、数值与容差仍待试玩评估，不能把自动化成功率当作玩家体验指标。
